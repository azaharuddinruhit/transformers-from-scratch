Page checks

Loads every page at several widths, with every part view shown and every collapsible box opened, and reports: maths that KaTeX did not render, symbols written as plain text, elements that stick out of their section, clipped text, and text boxes that need sideways scrolling (code, tables and display equations may scroll). Open this file in Chrome (started with --allow-file-access-from-files), or run it headless with --dump-dom; the result appears below when the status line says “done”.
